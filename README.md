# 🎬 Movie Ticket Management System

## 📖 Project Overview
The Movie Ticket Management System is a web-based application developed to simplify the process of booking movie tickets online. It allows users to view available movies, select seats, and book tickets efficiently. The system also enables administrators to manage movie details, schedules, and bookings.

## ✨ Features
- User Registration and Login
- Browse Available Movies
- View Show Timings
- Book Movie Tickets
- Seat Selection
- Booking Confirmation
- Admin Panel for Movie Management
- Database Storage using MySQL

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## 📁 Project Files
- HTML pages
- CSS stylesheets
- JavaScript files
- PHP backend files
- MySQL database (.sql)
- Project Presentation (PPT)

## 🚀 How to Run the Project
1. Install XAMPP or WAMP.
2. Copy the project folder to the `htdocs` folder.
3. Start Apache and MySQL.
4. Import the MySQL database using phpMyAdmin.
5. Open your browser and visit:
   ```
   http://localhost/your-project-folder
   ```
